# 薄型二つ折り財布（立体ポケット＋上部ファスナー小銭入れ）設計図

ラフスケッチと右側の型紙イメージをもとに寸法を決めた、レザークラフト用の設計図です。Jw_cad で開いて編集できる DXF 形式です。

| `wallet_assembly_A3.dxf` | **組立図**：完成状態の内側図、閉じたときの重なり、断面 A-A／B-B／C-C、閉じた状態を上から見た図、仕様、作り方 |

## Jw_cad での開き方

1. Jw_cad の用紙サイズを **A-3**、縮尺を **S=1/1** にする。
2. ［ファイル］→［DXF形式ファイルを開く］で `.dxf` を開く。
3. 縮尺が 1/1 でなければ［設定］→［縮尺・読取］で 1/1（実寸固定）にする。必要なら `.jww` で保存する。

- 形式は AutoCAD R12 の ASCII DXF、文字コードは Shift-JIS。原点 (0,0) は A3 用紙の中心です。
- レイヤ：`切断線` `縫い線` `山折り` `谷折り` `中心線` `貼り位置` `ファスナー` `カード` `お札` `小銭` `芯材・裏地` `寸法` `文字` `断面図` `図枠`
- 印刷したら、左下の 100mm スケールで倍率を確認してください。

## 構造

![組立図](preview_assembly.png)

- **お札**：折らずに入れます（160×76）。左半分は外装の左側に出ていて、左下の角を④ベルトに差し込みます。右半分は右側ユニットの下に入ります（上辺・左辺が開いているので、そこから差し込む）。
- **外装の内側**：全面に⑦裏地（布）を貼ります。左側（お札側）だけは、外装と裏地の間に⑧芯材を挟んで張りを出します。芯材は中心の折り目と縫い線にはかけません。
- **右側ユニット**（②台座＋③前胴＋⑥a/⑥b）：外装には**右辺と下辺**で縫い付けます。
- **③前胴は立体**：タブ（幅6）を②に縫い付け、壁（高さ6）を手前に折り上げると箱になります。
  - **小銭入れ**：**ファスナーは最上部**にあり、務歯が②と③の上端の間に出ます。財布を閉じたままでも開けられます。
  - **カードポケット**：6枚程度入ります。左の差込口から入れ、右下の窓に指をかけて左へ滑らせて出します。カード面の裏には⑨裏地（布）を貼り、カードが滑りやすいようにします。
  - **窓と角押さえ**：旧⑤カード押さえは③に一体化しました。窓は 45° の斜めのくり抜きで、③の角は鈍角（135°）になります。窓の下の角押さえは右タブ・下タブで③とつながっているので、カードが少ないときでも右下が飛び出しません。右側の押さえ（窓より上の壁）は 12.5mm から約 20mm に伸びました。
- **窓とベルト**：左の④ベルトと右の窓は、中心線に対して対称です。窓はベルトより**両側1.5mm広く**してあるので、多少ずれても閉じたときにベルトが窓に収まります。
- **裏ポケット**：②の裏に布のポケットを2段付けます。**上から入れる**ポケットで、左辺・右辺・下辺を縫います。上端は斜め（左が低い）で、⑥b は ⑥a より 12mm 下げて重ねています。
- **厚み**：閉じた状態で約 10〜13mm（中身による）。

## 布（裏地・裏ポケット）について

財布の内側やカードポケットの裏によく使われる薄い素材には、主に次のようなものがあります。

| 素材 | 厚み目安 | 特徴 | 端の処理 |
|---|---|---|---|
| **ナイロン**（ツイル・タフタ） | 0.1〜0.3mm | 薄くて丈夫。表面がすべるのでカードやお札を出し入れしやすく、水にも強い。財布の裏地の定番 | 切り口はほつれる。ライターやヒートカッターで軽く溶かして止める |
| **ポリエステル**（ツイル・サテン・ジャカードなど） | 0.1〜0.3mm | ナイロンに近い性質。光沢や柄のあるものが多い | ナイロンと同じく熱で止められる |
| **綿**（コットンツイル・シーチングなど） | 0.2〜0.5mm | 手に入りやすく、風合いがやわらかい。汚れ・湿気にはやや弱い | 熱では止められないので、折り返すか、ほつれ止め液を塗る |
| **人工スエード**（マイクロファイバーの不織布） | 0.4〜0.8mm | 切りっぱなしでもほつれない。少し厚く、値段は高め | 不要 |

**おすすめはナイロンツイル（0.2mm前後）**です。⑦⑨⑥すべて同じ布で作れます。

扱い方のコツ：

- 裏ポケットの入口（上端）は、型紙の折り返し代 6mm を内側（②側）へ折って貼ります。必要なら上端から 3mm を押さえ縫いします。
- 布の端は革のコバより 0.5mm 内側に収まるように型紙を作ってあります。縫い代に入る部分は、ほつれ止めをしておきます。
- ⑦裏地は外装の内側に全面接着します。接着剤は薄く均一に塗ります。中心の折り目の部分は特に薄くして、折り目が硬くならないようにします。
- ⑨は③のカード面の裏に貼ります。差込口と窓の自由辺からは 1mm 内側に収まります。
- 布は伸びやすいので、軽く張ってしわが出ないように貼ります。

## 作り方の順序

1. 裁断し、床面を処理する。③の折り線（山折り＝一点鎖線、谷折り＝破線）に溝を入れ、窓をくり抜く。組み立て後に磨けない自由辺（差込口・窓・④）のコバを先に仕上げる。
2. ①の左側に⑧芯材を貼り、⑦裏地を内側全面に貼る（折り目は接着剤を薄く）。
3. ④ベルトを⑦の上に貼る。③のカード面の裏に⑨裏地を貼る。
4. ファスナーを付ける。下側テープを③の上端の裏に、上側テープを②の上端の表に貼り、どちらも上端から 2.5mm の位置で縫う。
5. ③のタブと谷を②に貼り、仕切りの谷（③＋②）を縫う。
6. ③の右タブ・下タブを②に貼る。このとき、カードを3枚ほど入れて壁を立てた状態で貼る。
7. ⑥a・⑥b の斜めの上端を折り返して貼る（押さえ縫いは任意）。②の裏に ⑥a→⑥b の順に、縫い代だけを貼る。
8. 左端の縦の線（③左タブ＋②＋⑥a＋⑥b）を上から下まで縫う。これでユニットが完成。
9. 外周を縫う。ただし、右辺・右下の角・ユニット部分の下辺は残しておく。
10. ユニットを①に重ねて縫い代だけ接着し、下辺→右下の角→右辺を全層まとめて縫う。
11. コバを仕上げる（布は 0.5mm 内側）。最後に中心に折り癖を付ける。

## 寸法を変えたいとき

`generate_wallet.py` の先頭にある「設計寸法」を書き換えて、次のコマンドで再実行すると DXF・PDF・PNG がすべて作り直されます。主な定数は次のとおりです。

- 全体：`W`、`H`
- ③の立体：マチ `G`、タブ `T`
- 差込口：`D_TOP_U`、`D_BOT_U`
- 窓とベルト：角度 `K_AB`、窓の余裕 `WIN_CLEAR`、ベルト位置 `A_EDGE_V`・`B_EDGE_V`
- 裏ポケット：斜めの上端 `POCKETS`（左端と右端の高さ）
- 芯材：`CORE_IN`、`CORE_FOLD`

左右の対称と、③の展開図（壁・タブ・窓のくり抜き）は自動で計算されます。

```
pip install matplotlib   # PDF/PNG プレビューが必要な場合のみ
python3 generate_wallet.py
```
