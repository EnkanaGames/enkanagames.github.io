# 薄型二つ折り財布（ファスナー小銭入れ付き）設計図

ラフスケッチをもとに寸法を決めた、レザークラフト用の設計図です。Jw_cad で開いて編集できる DXF 形式で用意しています。

## ファイル

| ファイル | 内容 |
|---|---|
| `wallet_pattern_A3.dxf` | **型紙**（実寸 1:1・A3横）：①外装 ②台座 ③前胴 ④札押さえベルト ⑤カード押さえ |
| `wallet_assembly_A3.dxf` | **組立図**：展開図、閉じたときの重なり確認図、断面模式図、仕様、作り方の順序 |
| `wallet_pattern_A3.pdf` / `wallet_assembly_A3.pdf` | 上の2枚を PDF にしたもの（A3・実寸で印刷可） |
| `preview_pattern.png` / `preview_assembly.png` | プレビュー画像 |
| `generate_wallet.py` | 図面の生成スクリプト（寸法を変えて作り直すとき用） |

## Jw_cad での開き方

1. Jw_cad を起動し、画面右下の用紙サイズを **A-3**、縮尺を **S=1/1** にしておく。
2. ［ファイル］→［DXF形式ファイルを開く］で `.dxf` を選ぶ。
3. 縮尺が 1/1 になっていなければ、［設定］→［縮尺・読取］で **1/1** に変更する（「実寸固定」）。
4. 必要に応じて［ファイル］→［名前を付けて保存］で `.jww` として保存する。

- 形式は AutoCAD R12 の ASCII DXF、文字コードは Shift-JIS です（Jw_cad が読める形式）。
- 原点 (0,0) は A3 用紙の中心です（Jw_cad の座標の原点は用紙中心のため）。
- 線種は破線・一点鎖線などのパターン長も DXF に書いているので、実線に化けにくいはずです。
- レイヤは用途ごとに分けています：`切断線` `縫い線` `折り線` `貼り位置` `ファスナー` `カード` `お札` `寸法` `文字` `断面図` `図枠`。
- 型紙を印刷するときは、左下の **100mm スケール** が実寸の 100mm になっているか確認してください。

## 構成（スケッチからの解釈）

![組立図](preview_assembly.png)

- **左半分**：お札スペース。お札は**二つ折り（約80×76mm）**にして入れ、左下の斜めベルト（④）で角を押さえます。
- **右半分**：上が**ファスナー付きの小銭入れ**、下が**カードポケット（6枚程度）**。
  - カードは左の斜めの差込口から入れます。右下の斜めの**窓**からカードが見えるので、そこに指をかけて左へスライドさせて取り出します。
  - 窓の外側の三角（⑤）はカードの右下の角を押さえます。
- **裏ポケット**：カード・小銭入れのユニット（②台座）と外装の間がポケットになります。入口は中心から 12mm の位置で、中心側を向いています。大きめのポイントカードはここに入れます。
- **左右の斜めラインは中心線を軸にした完全な左右対称**です。閉じると左の④ベルトが右の窓にぴったり重なり、ベルトの出っ張りが窓のくぼみに収まります（組立図右上の確認図と断面 B-B で確認できます）。

## 部品と材料

| No. | 部品 | 数 | 革厚の目安 |
|---|---|---|---|
| ① | 外装 | 1 | 1.2〜1.4mm |
| ② | 台座（裏ポケット／小銭入れ・カードの背面） | 1 | 0.8〜1.0mm |
| ③ | 前胴（小銭入れの前面＋カードポケット） | 1 | 0.8〜1.0mm |

- 3号コイルファスナー 1本：テープ長 81mm、窓長 71mm に合わせて止め金具を付ける。上側のテープは上端から 4mm の位置でカットする（型紙の緑破線）。
- ロウ引き糸 0.45〜0.55mm：約 3.5〜4m（縫い線の長さは外周 579mm、ファスナー窓 169mm、L字 118mm）。
- 接着剤（ゴム系または水性）、床面処理剤（トコノールなど）。

## 作り方の順序

1. 裁断する。床面を処理し、組み立て後には磨けない辺のコバを先に仕上げる。対象は③の窓・差込口・右下の斜辺、⑤の斜辺、④の斜め2辺、②の左端。
2. ③前胴の窓の両端を φ7mm のポンチで抜き、間を直線でカットする。裏にファスナーを貼り、窓のまわりを縫う。
3. ③前胴と②台座の上辺・右辺・左辺をそろえて重ね、L字の縫い線（小銭入れの左側＋仕切り）を縫う。小銭入れの左端（2枚重なる部分）のコバを仕上げる。
4. ⑤と③下部の縫い代を②に貼る。カードを3枚ほど挟んだ状態で貼ると、6枚入るゆとりができる。
5. ②③⑤のユニットを外装の右側に貼る。貼るのは**外周の縫い代（幅5mm）だけ**にする。内側まで貼ると裏ポケットがふさがってしまう。
6. ④ベルトを外装の左下に貼る。二つ折りのお札を数枚挟んだ状態で貼ると、ゆとりができる。
7. 外周を一周縫い、外周のコバを仕上げる。最後に中心に折り癖を付ける。

## スケッチから変えた点・決めた点

- **お札のサイズ**：スケッチの比率から、二つ折りのお札（一万円札 160×76 の半分）を前提にしました。
- **小銭入れとカードの前面は1枚（③前胴）にまとめ**、仕切りの縫い線で上下に分けています。重なりが減るので薄くなります。
- スケッチ右端の、仕切りあたりにある**半円の切り欠きは省きました**。そのまま切ると小銭入れの右下の角が開いて、小銭がこぼれるためです。
- 小銭入れの左下の角は、小銭が溜まりにくいように縫い線を R6 にしています。前胴の左側はその縫い線に沿った段（R9）から、カード差込口の斜め辺へつなげています。
- ファスナー窓の幅は 3号コイル（エレメント幅 約4mm）を想定して 7mm にしています。使うスライダーが引っかかる場合は 8mm に広げてください。

## 寸法を変えたいとき

`generate_wallet.py` の先頭にある「設計寸法」の定数（`W`、`H`、`UNIT_L`、`SEP_V`、`A_EDGE_V` など）を書き換えて、次のコマンドで再実行すると DXF・PDF・PNG がすべて作り直されます。左右の斜めラインは自動的に対称になります。

```
pip install matplotlib   # PDF/PNG プレビューが必要な場合のみ
python3 generate_wallet.py
```

Jw_cad 上で直接修正しても問題ありません。
