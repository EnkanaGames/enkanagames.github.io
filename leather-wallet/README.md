# 薄型二つ折り財布（立体ポケット＋上部ファスナー小銭入れ）設計図

ラフスケッチと右側の型紙イメージをもとに寸法を決めた、レザークラフト用の設計図です。Jw_cad で開いて編集できる DXF 形式です。

## ファイル

| ファイル | 内容 |
|---|---|
| `wallet_pattern_A3.dxf` | **型紙**（実寸 1:1・A3横）：①外装 ②台座 ③前胴（立体の展開図） ④札押さえベルト ⑤カード押さえ（立体） ⑥裏ポケット板 |
| `wallet_assembly_A3.dxf` | **組立図**：完成状態の内側図、閉じたときの重なり、断面 A-A／B-B／C-C、閉じた状態を上から見た図、仕様、作り方 |
| `wallet_pattern_A3.pdf` / `wallet_assembly_A3.pdf` | 上の2枚の PDF（A3・実寸で印刷可） |
| `preview_pattern.png` / `preview_assembly.png` | プレビュー画像 |
| `generate_wallet.py` | 図面の生成スクリプト（寸法を変えて作り直すとき用） |

## Jw_cad での開き方

1. Jw_cad の用紙サイズを **A-3**、縮尺を **S=1/1** にする。
2. ［ファイル］→［DXF形式ファイルを開く］で `.dxf` を開く。
3. 縮尺が 1/1 でなければ［設定］→［縮尺・読取］で 1/1（実寸固定）にする。必要なら `.jww` で保存する。

- 形式は AutoCAD R12 の ASCII DXF、文字コードは Shift-JIS。原点 (0,0) は A3 用紙の中心です。
- レイヤ：`切断線` `縫い線` `山折り` `谷折り` `中心線` `貼り位置` `ファスナー` `カード` `お札` `小銭` `寸法` `文字` `断面図` `図枠`
- 印刷したら、左下の 100mm スケールで倍率を確認してください。

## 構造

![組立図](preview_assembly.png)

- **お札**：折らずに入れます（160×76）。左半分は外装の左側に出ていて、左下の角を④ベルトに差し込みます。右半分は右側ユニットの下に入ります。
- **右側ユニット**（②台座＋③前胴＋⑤＋⑥）：外装には**右辺だけ（ヒンジ）**で縫い付けます。ページのようにめくれるので、その下にお札の右半分を入れます。
- **③前胴は立体**：タブ（幅6）を②に縫い付け、壁（高さ6）を手前に折り上げると箱になります。いただいた型紙イメージの「黄色＝折り上げる部分」「青＝縫う部分」と同じ考え方です。
  - **小銭入れ**：上が③の面、下が仕切りの谷です。**ファスナーは最上部**に付けます（務歯が②と③の上端の間に出る）。財布を閉じたままでも上端のファスナーを開けて小銭を出せます。開けてから両端を軽く押すと口が開きます。
  - **カードポケット**：6枚程度。左の斜めの差込口から入れます。右下の窓（④ベルトと左右対称）に指をかけて、左へ滑らせて取り出します。
- **裏ポケット**：②と⑥の間です。入口は左端（中心から12mm）で、約88×60mm まで入ります。
- 左の④ベルトと右の窓は中心線で**左右対称**なので、閉じるとぴったり重なります。

| No. | 部品 | 数 | 革厚の目安 |
|---|---|---|---|
| ① | 外装 | 1 | 1.2〜1.4mm |
| ② | 台座（小銭・カードの背面） | 1 | 0.8〜1.0mm |
| ③ | 前胴（立体：小銭入れ＋カードポケット） | 1 | 0.8mm（折りやすい柔らかめの革） |
| ④ | 札押さえベルト | 1 | 1.0mm |
| ⑤ | カード押さえ（立体） | 1 | 0.8mm |

- 3号コイルファスナー 1本：務歯 81mm（止め金具の間）、テープ長 約90mm。テープは務歯から内側へ 12mm を残してカットする。
- ロウ引き糸 0.45〜0.55mm：約5m（縫い線の合計は約94cm）。
- 接着剤、床面処理剤。③⑤の折り線は、床面に溝を入れるか漉いておくと折りやすくなります。

## 作り方の順序

1. 裁断し、床面を処理する。③⑤の折り線（山折り＝一点鎖線、谷折り＝破線）に溝を入れる。組み立て後に磨けない自由辺（差込口、斜辺、④、⑥の上端と左端）のコバを先に仕上げる。
2. ファスナーを付ける。下側テープを③の上端の裏に、上側テープを②の上端の表に貼り、どちらも上端から 2.5mm の位置で縫う。
3. ③のタブと谷を②に貼り、左タブ（中心から15mm）を縫う。
4. ⑥を②の裏に重ね、仕切りの谷を ③＋②＋⑥ まとめて縫う。
5. ③⑤の下タブと右タブを②に貼る。このとき、カードを3枚ほど入れて壁を立てた状態で貼る。
6. 下端（③⑤の下タブ＋②＋⑥）を縫う。これでユニットが完成。
7. ①に④を貼り、外周を右辺以外すべて縫う。
8. ユニットを①の右に重ね、右辺（ヒンジ）を全層まとめて縫う。**ユニットと①は接着しない**（めくれるようにするため）。
9. 右辺のコバを仕上げ、中心に折り癖を付ける。

## 寸法を変えたいとき

`generate_wallet.py` の先頭にある「設計寸法」（`W`、`H`、マチ `G`、タブ `T`、`CB`、斜めライン `A_EDGE_V` など）を書き換えて、次のコマンドで再実行すると DXF・PDF・PNG がすべて作り直されます。左右の対称と、③⑤の展開図（壁とタブの分）は自動で計算されます。

```
pip install matplotlib   # PDF/PNG プレビューが必要な場合のみ
python3 generate_wallet.py
```
